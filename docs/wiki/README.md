# RE0 HD 지도 모드 위키

[한국어](README.md) | [English](README.en.md)

바이오하자드 제로 HD 리마스터(Resident Evil 0 HD REMASTER) 주석 지도 모드(프로젝트 `resident-evil-0-annotated-map`)의 기능·사양·배치 규칙을 다른 지도 모드 프로젝트(RE1, RE1 HD, RE2, RE3, Dino Crisis)가 재사용하도록 정리한 개발자용 참고서입니다. 사용자 설명서가 아니며, 사용자 설명서는 [README](../../README.ko.md)입니다.

## 다른 프로젝트에서 쓰는 법

1. 먼저 [08 이식 점검표와 교훈](08-porting-lessons.md)을 읽습니다. 첫머리 표가 모든 규칙이 일반 규칙인지 RE0 전용인지, 어느 페이지에 있는지 알려줍니다.
2. 모든 페이지는 두 구역으로 나뉩니다. **일반 규칙 (다른 RE 시리즈 공통)** 은 RE0 이름 없이 쓰여 있어 그대로 복사할 수 있습니다. **RE0 HD Remaster 전용** 에는 주소, 오프셋, 데이터 형식, 게임 동작, 아트 참조와 이 게임에 맞춘 수치가 있습니다. 앞 구역을 복사하고, 뒤 구역은 사례로 보되 수치는 대상 게임에 맞게 다시 구하세요.
3. 분류하지 못한 내용은 추측하지 않고 **미분류** 로 표시했습니다.
4. 모든 수치는 RE0 프로젝트의 코드와 `verification/`, `data/`의 파일에서 가져왔습니다. 인용은 RE0 프로젝트 루트 기준 경로입니다.
5. 증거 수준: **정적**(코드·데이터 판독), **합성**(오프라인 하니스·에뮬레이터), **실게임**(실행 중인 게임에서 확인). 대부분은 정적 또는 합성이며, 실게임에서 본 것은 해당 페이지에 적었습니다.

## 알려진 한계 (요약, 상세는 각 페이지)

- 오버레이가 피하는 프레임 사각형은 2560x1440 스크린샷 한 장에서 실측했습니다 ([03](03-placement-rules.md)).
- 여러 층에 걸친 13개 방의 버린 아이템은 데이터만으로 층을 정할 수 없으며, 2개 방만 추정 높이 기준을 씁니다 ([05](05-data-conditions.md)).
- 파트너 캐릭터와 시나리오 차이는 추적하지 않았습니다 ([05](05-data-conditions.md)).
- "본 아이템만 표시" 기능은 보류입니다. 게임에 아이템별 발견 기록이 없습니다 ([05](05-data-conditions.md)).
