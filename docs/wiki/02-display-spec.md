# 02 표시 사양

[한국어](02-display-spec.md) | [English](02-display-spec.en.md) · [Index](README.md)

경로는 RE0 프로젝트 루트 기준입니다. 인용은 파일과 함수 이름만 적고 줄 번호는 적지 않습니다.

## 일반 규칙 (다른 RE 시리즈 공통)

### 좌표 모델

- 게임의 지도 GUI에는 고정된 가상 캔버스가 있습니다. 모든 위치, 방 상자, 배치는 캔버스 단위로 저장하고, 뷰 `(scale, ox, oy)`로 화면에 옮깁니다. 화면 계수는 `백버퍼 높이 / 캔버스 높이`입니다.
- 뷰는 게임이 실제로 그린 방 상자(캡처)에서 추정하고 빌드 때 저장한 상자와 대조합니다. x와 y의 배율이 2% 이내로 일치하고 모든 상자 가장자리가 4px 이내일 때만 받아들이며, 아니면 위치 표식을 그리지 않고 캡처된 상자 옆에 개수를 표시하는 방식으로 되돌아갑니다.
- 크기는 높이만으로 확대됩니다. 너비는 무시하고 게임 자체의 렌더 사각형을 써서 16:9 화면을 가운데 놓는 와이드 디스플레이에서도 정렬을 유지합니다.
- 범례 같은 패널은 별도 계수 `height / 1440`을 씁니다. 1440p용으로 만든 래스터가 1440p에서 1:1 픽셀을 유지하게 하기 위해서입니다.

### 확대 곡선

- 게임의 확대는 0..1 진행값이 1배~최대 배율(여기서는 3배)의 지도 배율로 바뀌는 것입니다. `t = clamp((view.scale / screen - 1) / (max - 1), 0, 1)`을 게임 메모리가 아니라 뷰에서 구합니다.
- **이름 확대:** `name_zoom(t) = Z0 + (1 - Z0) * t`. 이름은 완전 확대에서 설정 크기, 축소에서 그 `Z0`배이며 확대 과정에서 지도를 따라갑니다. 방 이름과 아이템 이름은 같은 곡선을 씁니다(테스트됨).
- **아이콘 크기** = `ICON_SIDE * 사용자% * screen * name_zoom(t) * gain(분류, t)`. `gain`은 분류별로 `t`에 대해 선형입니다. 적은 그대로 두고, 핵심 아이템과 문 열쇠는 10%를 더하며, 문 열쇠는 확대할 때 다른 아이콘보다 더 빨리 커지게 합니다.
- 표식 한 변은 한 함수로 구하고 모든 소비자(예약, 화면 밖 판정, 범례 겹침 판정, 충돌 상자, 버린 아이템 아이콘)가 그 함수를 씁니다. 공식이 둘이면 어긋납니다.

### 불투명도와 색

- 이름 불투명도는 정점 색의 알파 바이트 `퍼센트 * 255 / 100`입니다. 아이콘 불투명도는 별개의 알파입니다. 섞지 않습니다.
- 아이콘은 흰색 아트에 알파만 곱하고, 이름은 분류 색을 씁니다. 한 분류의 범례 줄, 표식 이름, 방 개수 배지는 같은 색을 씁니다.
- 분류마다 색 하나, 순서 고정. 꺼진 줄은 같은 줄을 회색으로 표시합니다.
- 퍼즐 표식은 `!`가 있는 주황 마름모, 이벤트 표식(독립 분류, 스포일러 장면)은 `?`가 있는 보라 마름모입니다. 마름모는 글꼴이 아니라 직접 그린 도형이며 밉 텍스처에 넣습니다. 흰 채움에 색을 곱하고 외곽선·기호는 어둡게 해서 작은 크기에서도 막대와 점이 떨어져 보이게 합니다. 마름모 모서리는 정사각 표식보다 한쪽에 `side / 9`만큼 더 나오므로 충돌·겹침 검사에 반영합니다.
- 버린 아이템 아이콘은 게임이 직접 그리는 색 점 위 가운데에 알파 65%로 둡니다. 점의 색과 깜박임이 보여야 하므로 어긋나게 놓지 않습니다.

### 글자 줄바꿈 규칙 (표식 이름)

1. 끝의 수량(`×N`, `N%`)은 항상 2줄째입니다.
2. 아니면 공백 포함 8자 이상 이름은 가운데에 가장 가까운 공백에서 줄바꿈합니다.
3. 한 단어는 쪼개지 않습니다(공백 없는 긴 이름은 한 줄).
4. 최대 두 줄. 수량이 있는 긴 이름은 이름 한 줄, 수량 2줄째입니다.
5. 적과 이벤트는 2줄째가 없습니다.
6. 각 줄은 별개의 래스터 글리프이며 줄바꿈된 전체 상자를 충돌 검사합니다.
7. 정렬은 이름이 놓이는 아이콘 쪽을 따릅니다: 아이콘이 왼쪽이면 왼쪽 정렬, 오른쪽이면 오른쪽 정렬, 위·아래면 가운데.
8. 방 이름: 방보다 150% 넘게 넓은 한 줄 이름은 공백이 있을 때만 단어 사이에서 줄바꿈합니다(03 참고).

### 이름 규칙

- 이름은 게임 자체의 아이템 이름이며, 대상 언어에 없으면 프로젝트가 번역합니다.
- `A의 B` 형태의 아이템 이름에서 조사(한국어 `의`)는 자연스러우면 뺍니다. 한 음절 어간이라 빼면 어색한 이름은 남기고, 예외 목록을 검수용으로 검증 파일에 둡니다.
- 수량: 더미에만 `×N`을 표시합니다. 무기는 수량을 표시하지 않습니다(양은 장전된 탄수). 수량 0, 1 또는 미설정이면 표시하지 않습니다. 원시 단위가 카탈로그 단위와 다른 탄약은 변환해 표시합니다.
- 적은 이름 없이 아이콘만, 이벤트도 이름을 표시하지 않습니다.
- 이름은 표시되는 크기에 가깝게 래스터화합니다(20px 래스터를 1.65배 늘리면 흐려졌습니다). 글자는 2px 어두운 외곽선을 둡니다.

### 분류별 아이콘 배율

`icon_gain(분류, t)`와 `mark_side`는 `frame.c`:

- 적: gain 1.0, 추가 없음.
- 문 열쇠(잠금 분류): `1.3 * (0.96 + (1.5 - 0.96) * t)`, 추가 1.1.
- 핵심 아이템: `1.3 * (1 + 0.3 * t)`, 추가 1.1.
- 문서, 퍼즐, 일반 아이템: `1.3 * (1 + 0.3 * t)`.

아이콘 크기 설정 100% 기준으로: 아이템과 핵심 아이템은 100% -> 130%, 문 열쇠는 96% -> 150%, 적은 1.3 기준 없이 1.0입니다. 확대 배율은 아이템 100 -> 130, 문 열쇠 96 -> 150이고 적은 확대하지 않습니다. 테스트: `tests/frame_contract.py`의 `icon_sizes`.

### 버린 아이템 아이콘

플레이어가 버린 아이템은 게임이 그리는 점(12x12 스프라이트, 2560x1440 3배 확대에서 배율 4) 위 가운데에 알파 65%로 그립니다. 점 색은 아이템 종류에 따라 다릅니다(Ink Ribbon 주황 `ff5800`, 허브 초록 `0fa932`, 탄약 파랑 `287aff`, 권총 빨강 `ff0038`, 핵심 아이템 노랑 `ffff28`). 종류별 색 대응은 이 5개 행에서 추정한 것입니다. 투영은 2560x1440에서 점과 0.4px 이내로 일치했습니다.

### 이름 글자 (한국어)

- `의` 규칙: 공백이 아닌 글자 뒤의 첫 `의 `를 제거합니다(`build_labels.py`). 33개 이름이 바뀌었고 7개는 유지: `선의 서`, `악의 서`, `백의 조각상`, `흑의 조각상`, `불의 열쇠`, `물의 열쇠`, `시의 한 구절`(`build_labels.py`, `verification/ko-name-changes.md`). 적 표식 이름은 전체 이름을 유지하고(`build_labels.py`) 방 이름에는 이 규칙을 적용하지 않습니다.
- 수량: 무기는 수량 없음, `amount <= 1` 또는 `>= 65535`는 수량 없음, Machinegun Ammo는 `(amount + 2) / 3 %`, 그 외는 `×N`(`build_labels.py`).
- 조제 허브(아이템 id 46~51): 이름은 `조제한 허브` / `Herbal Mix` 하나로 통일하고 아이콘만 여섯 가지를 구분합니다(프로젝트 결정).
- 줄바꿈 코드: `build_labels.py`(분할), `221`(적·이벤트는 2줄째 없음), `frame.c`(상자와 정렬; 2줄째 위쪽은 1줄째와 래스터 10px, 즉 타일 여백만큼 겹침).
- 방 이름 래스터: 글꼴 30px, 외곽선 2px, 타일 안쪽 여백 6px(`build_labels.py`).
- 전체 데이터 줄바꿈 감사: 한국어 한 줄 197, 줄바꿈 42, 수량 있음 140; 영어 한 줄 29, 줄바꿈 210, 수량 있음 140. 8자 이상 한 단어 라벨은 한 줄 유지: Briefcase, Hookshot, Motherboard.

### 미분류

- 축소 시 이름 배율 0.7과 아이콘 배율 1.3/1.5를 다른 게임이 유지해야 하는지는 이 게임의 아이콘 아트와 확대 범위에 맞춰 조정한 값이라 판단하지 않았습니다.
