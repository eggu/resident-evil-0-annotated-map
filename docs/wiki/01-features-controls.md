# 01 기능과 조작

[한국어](01-features-controls.md) | [English](01-features-controls.en.md) · [Index](README.md)

경로는 RE0 프로젝트 루트 기준입니다. 인용은 파일과 함수 이름만 적고 줄 번호는 적지 않습니다.

## 일반 규칙 (다른 RE 시리즈 공통)

### 갖추면 좋은 사용자 기능

| 기능 | 규칙 |
| --- | --- |
| 방 이름 | 게임 자체 지도 위에, 두 언어로, 실행 중 전환 가능하게 그립니다. |
| 분류 표식 | 범례 순서의 7개 분류: 잠긴 문, 핵심 아이템, 문서·지도, 퍼즐, 이벤트, 일반 아이템, 적. 분류마다 색(INI에서 변경 가능), 토글, 범례 줄이 있습니다. 이벤트(보라색 `?` 마름모)는 컷신 시작과 적 등장 지점 같은 스포일러 장면이며 일어난 뒤에는 숨겨집니다. 퍼즐(주황색 `!` 마름모)은 아이템이나 풀이가 필요한 장치입니다. |
| 전체 토글 | 모든 주석을 숨깁니다. 토글을 읽고 되돌릴 수 있도록 범례는 남깁니다. |
| 방 이름 토글 | 표식과 독립된 이름만의 토글. |
| 방 범위 | 3단계: 방문한 방, 가진 지도로 공개된 방, 그려진 층의 모든 방. |
| 아이템 이름 | 3단계, 키 하나로 순환합니다: 모두, 일반 제외, 끔(기본 끔). 범례 줄에 현재 단계가 보입니다. 「일반 제외」에서는 일반 아이템 이름(떨어진 일반 아이템 포함)만 빠지고 나머지 이름은 제자리를 지킵니다. |
| 크기·불투명도 | 이름 크기, 이름 불투명도, 아이콘 크기, 아이콘 불투명도. 각각 전용 키, 10 단위 변경, 고정된 범위. |
| 범례 | 왼쪽 아래 패널. 분류가 꺼지면 해당 줄이 회색이 되고, 키 하나로 한 줄 안내로 접습니다. |
| 수치 패널 | 오른쪽 아래 패널에 크기·불투명도 4개 값을 표시하고 범례와 함께 접힙니다. |
| 상태 추적 | 아이템을 얻거나 퍼즐을 풀거나 문을 열거나 적을 죽이면 표식이 사라집니다. 난이도는 사용자에게 묻지 않고 게임에서 읽습니다. |
| 버린 아이템 | 플레이어가 버린 아이템도 그립니다(05 참고). |
| 디버그 캡처 | 키 하나로 현재 지도 기하, 진행 플래그, 스프라이트 덤프를 모드 옆에 써서 오프라인 재생에 씁니다. |

### 조작 규칙

- 키는 모드 오버레이가 지도 위에 그려지는 동안, 게임 창이 포커스일 때만 동작합니다. 키는 게임에도 전달되므로 게임이 쓰지 않는 키를 고르세요. 배정 전에 게임 `config.ini`의 키 목록을 읽습니다.
- 게임이 Shift(조준·달리기)를 쓰면 보조 키는 Shift 대신 Ctrl을 쓰고 Alt는 피합니다.
- 모든 토글에 쉬는 시간(디바운스)을 둡니다. 실게임 로그에서 한 번의 누름이 200 ms 간격으로 세 번 들어간 일이 있었습니다.
- 바뀐 설정은 즉시, 임시 파일에 쓴 뒤 원자적으로 교체해 저장합니다. 저장이 실패하면 이전 파일을 유지하고 로그에 남깁니다.
- 범례의 `0`~`9` 줄은 항목이므로 괄호를 유지하고, 나머지 키 안내는 한 형식으로 씁니다: 키, 라벨, 값 순서, 대안은 `/`, 조합은 `+`, 괄호 없음.
- 디버그 전용 키(방 선택)는 저장하지 않고 범례에 줄을 두지 않습니다.

### 설정 파일 규칙

- `Version` 키를 둡니다. 척도가 바뀌면 옛 값을 한 번만 변환하고, 새 버전으로 파일을 다시 쓰며, 두 번 변환하지 않습니다.
- 없는 크기 키는 기본값을 쓰고, 불투명도는 척도와 무관하므로 그대로 둡니다.
- 읽을 때 모든 값을 범위로 자릅니다. 잘못된 값이 모드를 멈추게 해서는 안 됩니다.
- 게임이 답하지 못할 때만 쓰이는 설정(무작위 모드의 난이도)은 파일에 남기되 키는 두지 않습니다.

사실:

- 숫자는 윗줄 키(`VK_0`~`VK_9`)이며 키패드 숫자는 읽지 않습니다. 키패드 `+`, `-`는 읽습니다(`re0_map.c`).
- 포커스 창이 게임 프로세스 소속이어야 합니다(`re0_map.c`). 키 처리는 그리기 게이트보다 먼저 실행되므로(`re0_map.c`, `508`) 게이트가 오버레이를 막는 중에도 캡처가 있으면 키가 동작합니다.
- 키당 디바운스 350 ms(`re0_map.c`).
- Shift가 아닌 Ctrl: 게임 `config.ini`가 `KC_kamae=KB_SHIFT`를 쓰고 Ctrl에 묶인 동작은 없습니다(`re0_map.c`). 지도 화면의 자체 입력 코드는 추적하지 않아 그곳에서 Shift의 효과는 알 수 없습니다.
- `~`는 게임 `config.ini`에서 쓰이지 않습니다(게임 `config.ini`가 나열한 키: W A S D Space Shift F 방향키 E V R Q C). 지도 화면이 다른 키를 읽는지는 추적하지 않았습니다.
- 게임패드 입력은 읽지 않습니다.
- `RE0Settings.hidden`("H를 누르는 동안 이름 숨김" 상태, `frame.c`)은 런타임이 설정하지 않습니다. "held H"를 언급한 주석(`frame.c`, `frame.c`)은 낡았습니다. H는 아이템 이름 토글입니다.

### 이전(마이그레이션)

- 이름 110%, 아이콘 130%가 새 기본 100%가 되도록 화면 크기에 `NAME_SIZE_BASE 1.1`, `ICON_SIZE_BASE 1.3`을 곱합니다(`frame.c`).
- `Version=44`가 없는 INI는 옛 척도로 한 번 읽습니다: `new = clamp(int(old/base + 5)/10*10)`, 기준은 이름 1.1, 아이콘 1.3(`frame.c`). 110 -> 100, 130 -> 100이 정확히 맞고, 없는 키는 100입니다. 이후 `Version=44`로 다시 씁니다(`re0_map.c`).
- 테스트: `tests/test_review44.py`(새 기본값, 한 번만 변환, 변환된 파일은 그대로 둠, 옛 격자 값마다 화면 크기가 반 단계 이내로 유지).

- `Version=50` 이전에 `ItemNames`는 켬/끔이었습니다. `re0_settings_item_names`가 옛 파일의 0이 아닌 값을 한 번 1(모두)로, 0을 0으로 읽고 `Version=50`으로 다시 씁니다. 이후에는 0–2를 유지하고 그 밖의 값은 0입니다. 위의 크기 변환은 `Version` 44 미만에만 적용됩니다(`RE0_SIZE_SCALE_VERSION`).
- 테스트: `tests/test_review50.py`, 계약의 `item_name_states`, 네이티브 디스패치 INI 게이트와 그 변이체.

- `Version=52` 미만 파일은 이벤트 비트(64)를 한 번 끕니다. 51까지 이벤트는 표식을 가진 퍼즐이었고 이후 버전이 퍼즐 비트를 이벤트에 복사했기 때문입니다(`re0_settings_contents`; 51에서 이벤트를 켠 채 저장한 파일도 꺼집니다). 52부터는 사용자의 선택(키 `6`)이 저장되어 유지됩니다. 범례 번호도 51에서 바뀌었지만(키 참고) 키는 저장하지 않으므로 `Contents`만 변환하면 됩니다.
- 저장은 INI를 제자리에서 고칩니다(`re0_ini_merge`): `[Map]` 키만 바뀌고 주석, 키 순서, 사용자의 `[Colors]`는 그대로이며, `[Colors]`가 없는 파일에는 기본값을 덧붙입니다. 테스트: `tests/test_review51.py`, 계약의 `category_rules`(병합 사례, 색 해석, 이벤트 비트), 네이티브 디스패치 INI 게이트(`Contents`, 실제 로더를 거치는 `[Colors]`)와 그 변이체.
